## 一、用户能看到的变化（UX 视角）

### 1. 标记现在能跟着「内部滚动容器」走了

**之前：** 整页滚动时标记跟随；但如果元素藏在某个**自带滚动条**的卡片 / 列表 / 模态体 / 抽屉里（最典型是 Try it 区域的 **Scrollable List**），在它内部滚动，标记不会动——结果就是"标记和元素分家"，过一会儿就找不到对应的位置。

**现在：** 不管是整页滚还是任何嵌套容器内部滚，标记都准确跟着目标元素移动；当目标被卷出可视区时，标记自动隐藏，滚回来又自动出现。

> 实现关键：`scroll` 不冒泡，所以在 `document` 上用 **capture 阶段** 监听才能收到嵌套容器的滚动事件；标记位置不再用绝对页面坐标，而是改为「点击时记录的目标内 0..1 比例 × 目标当前 `getBoundingClientRect()`」；标记和 spotlight 都按祖先链上每个 `overflow: hidden/auto/scroll` 的容器做 **clipping 计算**，被裁掉就藏起来。`requestAnimationFrame` 合并高频 scroll 事件防止抖动。

### 2. 设置面板第二项：**Marker display**（标注展示控制）

齿轮 → Settings 里，在 Output format 下面新增一节 **Marker display**，两个互斥选项：

| 选项 | 行为 |
|---|---|
| **Current page**（默认） | 维持现状：目标元素不在 DOM、被裁掉、在关着的弹窗 / 抽屉里时，**不显示**对应标记。 |
| **All markers** | 显示所有标注。无法定位到可见元素的，渲染为 **半透明虚线幽灵标记**（位置用标注创建时的视口坐标）；悬停预览底部多一行黄色提示 "Hidden — click to reveal or scroll into view"。 |

**目的：** 避免你"打了标记 → 关掉弹窗 → 一会儿全忘了里面还有未处理项"的情况。

#### 点击幽灵标记会自动 reveal

在 **All markers** 模式下，点击一个幽灵标记会按顺序尝试：

1. 目标在 DOM 但被 overflow 容器裁掉 → `scrollIntoView({ block: 'center', behavior: 'smooth' })`，把它滚回中央
2. 目标已经从 DOM 卸载（如关闭的 Vue v-if 弹窗）→ 查找 `[data-instruckt-open="<revealHost>"]` 并 `.click()` 触发宿主面板打开
3. 不管 reveal 成功与否，最后都会**打开编辑弹窗**——这样即使无法定位元素，至少能看到内容、修改、删除

#### 协作约定（让自动 reveal 在你的弹窗上工作）

无需写 JavaScript，只需要在 HTML 上加两个一一对应的属性：

```html
<!-- 打开弹窗的按钮：声明它能打开哪个面板 -->
<button data-instruckt-open="checkout-modal" @click="openModal">Checkout</button>

<!-- 弹窗根节点：声明自己的标识 -->
<div v-if="modal.open" class="modal" data-instruckt-host="checkout-modal">
  ...
</div>
```

标注创建时，instruckt 会自动从被标注元素往上找最近的 `data-instruckt-host`，把它写进 annotation 的 `revealHost` 字段。后续点击对应幽灵标记时，根据这个 key 找到 `[data-instruckt-open=...]` 并触发它。

**渐进增强：** 不加这俩属性，幽灵标记照样能显示，只是不会自动打开面板；用户依然能点击它直接进入编辑弹窗。

#### 持久化

选择按域名持久化到 `localStorage`（与 Output format 共用 key `instruckt:<origin>:settings`），下次回到同站点自动还原。

## 三、验证清单（自测时建议按顺序走一遍）

1. **嵌套滚动跟随** —— 在 **Scrollable List** 的某一行里打标记 → 在列表 **内部**上下滚动 → 标记应跟着目标行移动；目标行滚出列表后标记自动消失；滚回来又出现。
2. **整页滚动跟随**（回归测试）—— 在任意位置打标记 → 滚动整个页面 → 标记跟随。
3. **Settings 新选项可见** —— 打开齿轮 → 看到 Output format **下方** 多了 Marker display 一节，两个按钮。
4. **持久化** —— 切到 All markers → 刷新页面 → 仍是 All markers；切回 Current page → 同样持久化。
5. **Current page 行为不变** —— 关闭弹窗 / 抽屉里的标注消失；打开后回来。
6. **All markers → 幽灵渲染** —— 在 Drawer 里打一个标记 → 关闭 Drawer → 该标记变半透明虚线幽灵；悬停看到黄色 hint。
7. **All markers → 点击 reveal** —— 点击上一步那个幽灵 → Drawer 自动打开 → 标记切回正常实心态 → 同时弹出编辑弹窗。
8. **Scrollable List 幽灵** —— 在列表里打一个标记 → 把列表滚动让它出可视区 → 切到 All markers → 出现幽灵 → 点击 → 列表自动滚回中央。
9. **空白 reveal 路径**（兼容性）—— 找一个未声明 `data-instruckt-host` 的关闭面板里的标注 → 点击幽灵 → 不会自动打开面板，但**编辑弹窗仍正常**打开（不应卡住）。

# 2026-05-11 改动说明

> 本批改动归属分支 `feat/ux-precision-and-output-formats`，对应 PR #1。
> 文档面向产品 / 设计 / 研发三类读者；上半部分是给非工程同学看的体验视角，下半部分是给研发的实现备忘。

---

## 一、用户能看到的变化（UX 视角）

### 1. 标记点终于"落在我点的那个地方"了

**之前：** 不管点在元素的哪个位置，标记点都默认贴在元素的左上角。多个标记落在同一个组件上时全挤在一起，分不清是哪个细节的反馈。

**现在：** 鼠标点哪儿，标记点的中心就出现在哪儿。点按钮的图标和点按钮的文案，会得到两个明显不同的位置，团队能一眼看出你想说的是哪块。

> 实现关键：`positionMarker` 现在直接用 `annotation.x / annotation.y`（点击瞬间记的坐标），并对 `.ik-marker` 应用 `transform: translate(-50%, -50%)` 让点击位置就是 marker 的几何中心。

---

### 2. 鼠标移到标记点上，会"高亮 + 显示反馈内容"

**之前：** 标记点只是一个序号小圆圈，看不出它对应页面上的哪块元素，也看不出当时写了什么。

**现在：**

- **数字变编辑图标** —— hover 标记时，圆圈里的序号会变成铅笔图标，提示这是可编辑的
- **半透明高亮框** —— 鼠标悬停时，被标注的元素四周会出现一圈半透明色块，告诉你"我说的就是这个区域"
- **悬浮内容卡** —— 同时在标记点上方（或下方，自动避让屏幕边缘）弹出一张小卡，显示当时写的反馈文字

> 实现关键：在 `AnnotationMarkers` 里新增 `spotlight` 和 `preview` 两个常驻 DOM 节点，hover 时按目标元素的实时 `getBoundingClientRect()` 定位。

---

### 3. 框选元素的高亮框现在贴合元素，不再外溢

**之前：** 进入 Annotate 模式 hover 元素时，蓝色选框比实际元素**大一圈（每边多 ~2px）**，看起来好像选中了边上的东西。

**现在：** 选框严丝合缝地贴在元素的真实边界上，不再有多余空隙。

> 实现关键：`ElementHighlight` 加上 `box-sizing: border-box`，让 2px 的边框画在 `getBoundingClientRect()` 返回的矩形**内部**，而不是溢出到外部。

---

### 4. 弹窗 / 抽屉里的标记，只在弹窗 / 抽屉打开时才显示

**之前：** 在 Modal、Drawer 里打的标记，关闭这些覆盖层后，标记点会"漏"到主页面上继续显示，跟主页面的标记混在一起，无法分辨是不是同一上下文的反馈。

**现在：** 关闭弹窗后，里面的标记会自动消失；下次打开同一个弹窗，标记又会回来。逻辑遵循"目标元素不在 DOM 或不可见，就藏起来"。

> 实现关键：`MutationObserver` 监听 `document.body` 的 `childList / subtree / attributes`，DOM 变化时 debounce 重新评估每个标记的目标元素是否仍然存在。

---

### 5. 滚动 / 视窗尺寸变化时，标记和高亮跟随元素移动

继承自现有架构（`window.addEventListener('scroll' / 'resize', reposition)`），但本次和上面几条联动后，整体跟随行为终于稳定可信。

## 二、新增功能

### 1. 工具栏新增「设置」入口

在工具栏的 "Clear"（清空）按钮**下方**新增一个齿轮图标，点击会在工具栏旁边弹出一个面板（对话框样式）。

- 面板位置自动避让屏幕边缘
- 点击面板外任意位置 / 工具栏被最小化时，面板自动关闭
- 拖动工具栏时，鼠标如果在面板内部，不会触发拖拽

这个设置面板**是一个容器**，本批改动只装了第一项功能（见下条），未来可以继续往里塞「主题切换」「快捷键自定义」「严重等级配色」等。

---

### 2. 设置面板首项：「Output format（输出格式）」选择器

把标注复制成 Markdown 给 AI Agent 用时，可以从四档详略中选一档。设计参考自 [Agentation 的 Output 文档](https://www.agentation.com/output)，**Markdown 语法也已严格对齐他们的样例风格**，确保跟同类工具或 AI Agent 的解析习惯兼容。

| 档位 | 适用场景 | 输出内容（粗体即字段名） |
|---|---|---|
| **Compact** | 小修小改 / 快速反馈 | Element、Feedback、Screenshot |
| **Standard**（默认） | 大部分日常情况 | + Path、`<框架>` 组件链（取末端 3 个）、Source、Classes、Nearby text、Severity |
| **Detailed** | 复杂问题 | + Position（合并 bbox）、`<框架>` 全量组件链、Intent |
| **Forensic** | 排查布局/样式 bug | + ID、完整组件栈（带 file:line）、Computed styles（约 16 项常用属性，实时读取） |

**特性：**

- 选择会持久化到 `localStorage`（key: `instruckt:<origin>:settings`），下次回到这个站点自动还原
- 复制按钮、提交标注后的自动复制，都会按当前格式输出
- **组件链字段名按框架自适应**：React 项目里显示 `**React:**`，Vue 项目里显示 `**Vue:**`，Svelte 显示 `**Svelte:**`，其他 fallback 为 `**Component:**`
- Forensic 档的 computed styles 是**导出时**实时从页面元素读取的，所以拿到的是"复制那一刻"的真实样式快照，不是标注时的快照

## 三、技术修复

| 项 | 文件 | 备注 |
|---|---|---|
| TypeScript 类型错误 `TS2322` | `src/ui/screenshot.ts` | `nodeFilter` 参数类型由 `HTMLElement` 改为 `Node`，并在函数内部用 `instanceof HTMLElement` 收窄 |

| 销毁清理 | `src/instruckt.ts` | `destroy()` 现在会断开 MutationObserver 并取消挂起的 rAF |

## 五、验证清单（自测时建议按顺序走一遍）

1. **标记点位置** —— 进入 Annotate 模式 → 点击一个大按钮的**右下角** → 标记圆圈中心应该出现在右下角，而不是按钮左上角。
2. **Hover 交互** —— 鼠标悬停标记 → 数字变铅笔图标 + 出现半透明高亮 + 出现内容卡。
3. **高亮贴合度** —— Annotate 模式下 hover 任意按钮，蓝框边缘应该正好贴在按钮边缘，不外溢。
4. **弹窗 / 抽屉隔离** —— 打开演示页的 Modal/Drawer → 在里面打一个标记 → 关闭 → 主页面上不应该残留这个标记 → 再打开同一个 Modal/Drawer → 标记应该回来。
5. **滚动跟随** —— 在长列表上打几个标记 → 滚动页面 → 标记应该跟着元素动。
6. **Settings 面板** —— 点齿轮 → 面板在工具栏旁边弹出 → 点面板外任意处 → 自动关闭。
7. **输出格式** —— Settings 里选不同档 → 点 Copy → 粘到任意 Markdown 编辑器 → 字段数随档位递增；切回 Compact 应该只有 Element + Feedback；切到 Forensic 应该有 Computed styles。
8. **持久化** —— 选完 Forensic → 关闭浏览器 → 重新打开演示页 → 设置面板里默认仍是 Forensic。
